# TaskNet mobile (Expo / React Native)

The TaskNet app for teachers and school staff. It uses the shared API client
and helpers in `packages/shared` and talks to the same FastAPI backend as the web app.

## What it covers

- **Login**, including choosing a role for accounts that hold several. The session token is kept in the device keychain (expo-secure-store).
- **Home**: open, submitted and missing counts, tasks due soon, tasks you manage, upcoming events.
- **Tasks**: tasks assigned to you and tasks you manage (common and special), with search.
- **Task detail**: submit a file or link report, unsubmit, and see your points. Reviewers see each assignee's status, can open a report, and can mark it Completed or Missing. Public and private comments.
- **Events**: upcoming, pending approval, past and your own proposals.
  - Event detail: approve, disable or re-enable.
  - Show the attendance and evaluation QR codes on screen.
  - Print or share the DepEd-format proposal as a PDF (expo-print).
- **Scan attendance**: the camera reads the Time In and Time Out QR codes. The app records the phone's location if you allow it. After Time Out it opens the activity evaluation.
- **Alerts**: notifications, with an unread badge.
- **More**: profile (view and edit contact and workload details), badges and timing points, personnel directory (with deactivate and reactivate for those allowed), and the audit log.

Creating tasks and event proposals, school years and the DepEd calendar are done
in the web app.

## Run

From the repository root, run `npm install` once. Then:

```powershell
copy mobile\.env.example mobile\.env   # set EXPO_PUBLIC_API_BASE to your computer's LAN IP
npm run mobile
```

Press `a` for an Android emulator or `i` for the iOS simulator, or scan the QR code with Expo Go.
The camera, location and secure storage work in Expo Go. A store build needs EAS
(`npx eas-cli@latest build`).

`EXPO_PUBLIC_WEB_BASE` is the address of the web app. The QR codes shown in the app
point there. Set it to an address the attendees' phones can reach.
